# Code of Conduct

This project follows a simple maintainer standard:

- Be respectful in issues, discussions, and pull requests
- Assume good intent, then ask for a reproduction
- No harassment, personal attacks, or spam
- Security reports go through [SECURITY.md](./SECURITY.md), not public issues

Maintainers may hide or close contributions that break these rules.

For this repository, contact the owner via GitHub: [iosrxwy](https://github.com/iosrxwy).
